# sernix

Portable NixOS flake for server configurations. Terminal-only — no desktop, no display manager, no rice.

## First Time Setup

**1. Clone**
```bash
git clone https://github.com/Sh0rtRound-wq/sernix ~/sernix
```

**2. Generate hardware config** (if not already present on the target machine)
```bash
sudo nixos-generate-config
```

**3. Auto-detect machine settings**
```bash
cd ~/sernix
bash load_info.sh
```
This fills `config.nix` with the hostname, GPU, CPU vendor, and power profile, then copies `/etc/nixos/hardware-configuration.nix` into the flake. Review it after and adjust anything it got wrong.

**4. Rebuild**
```bash
sudo nixos-rebuild switch --flake ~/sernix
```

---

## Config fields

`config.nix` is generated by `load_info.sh`. Fields:

| Field | Values |
|-------|--------|
| `hostname` | machine hostname |
| `powerProfile` | `"performance"`, `"balanced"`, `"power-saver"` |
| `cpuVendor` | `"amd"`, `"intel"` |
| `gpu` | `"amd"`, `"intel"`, `"nvidia"`, `"prime-nvidia-amd"`, `"prime-nvidia-intel"`, `"none"` |
| `nvidiaBusId` | PRIME only, e.g. `"PCI:1:0:0"` |
| `amdBusId` | PRIME only |
| `intelBusId` | PRIME only |

## Before pushing changes from another machine

Reset `config.nix` and `hardware-configuration.nix` to stubs so machine-specific files don't end up in the repo:

```bash
bash load_info.sh --stub
git add config.nix hardware-configuration.nix
git commit -m "reset stubs"
git push
```

Then on the target machine, run `load_info.sh` again to restore.
